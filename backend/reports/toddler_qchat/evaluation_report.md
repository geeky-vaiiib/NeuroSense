### Label provenance
Target = the dataset's `group` field (1 = ASD, 7 = control). The page describes the ASD group as "a community-based diagnosis of autism spectrum
disorders"; the diagnostic instruments (ADOS-2, ADI-R, DSM-5) are **not documented** for this sample, so rigour is unverified. The label is
independent of the Q-CHAT answers (it is not a threshold on them): no total reproduces it, and a label-permutation control scores AUC
0.43, 0.50, 0.51, 0.42, 0.51 (≈ 0.5). It is **not** a clinically validated diagnosis for NeuroSense.

### Ten-item mapping (Allison, Auyeung & Baron-Cohen 2012, Table 3; checked against the dataset's own Polish value labels)
| NeuroSense | Q-CHAT item | dataset column | Q-CHAT-10 official point |
|---|---|---|---|
| Q1 name | 1 | qchat1recode | C/D/E |
| Q2 eye contact | 2 | qchat2recode | C/D/E |
| Q3 points to ask | 5 | qchat5recode | C/D/E |
| Q4 points to share | 6 | qchat6recode | C/D/E |
| Q5 pretend | 9 | qchat9recode | C/D/E |
| Q6 follows gaze | 10 | qchat10recode | C/D/E |
| Q7 comforts | 15 | qchat15recode | C/D/E |
| Q8 first words | 17 | qchat17recode | C/D/E |
| Q9 gestures | 19 | qchat19recode | C/D/E |
| Q10 stares at nothing | 25 | qchat25recode | **A/B/C** (option order runs most→least atypical) |

Encoding: the client sends the option letter A–E; the server derives `recode` 0–4 (higher = more atypical; Q10: 4 − index). The official point is `recode ≥ 2`
for every item. No agree/disagree coercion exists. Wording is the official English ARC wording (the dataset itself is Polish).

## 2. Method (declared before the run in the training script docstring)
* **Predictors**: config A = the ten item recodes; B = A + age (months) + sex; C (information only, never deployable) = B + other demographics.
  Excluded from every config: child id, `Sum_QCHAT`/any total, `group`, recruitment source, `sibling_withASD`, `siblings_number`.
* **Split**: one participant-level stratified holdout, 25% (dev n=189: 101 ASD / 88 control;
  holdout n=63: 34 / 29); strata = class × recruitment source; participant overlap = 0.
  The split is in `participant_split.csv`.
* **Model selection (dev only)**: nested: outer 5x5-fold stratified, inner 5-fold grid search (ROC-AUC); candidates logistic regression, decision tree, random forest, gradient boosting, SVC (RBF).
  Selection rule: one-SE rule on dev nested-CV ROC-AUC, simplest first; config A (items only) is the deployed questionnaire schema.
* **Threshold and calibration (dev only)**: Youden J on (recalibrated) dev out-of-fold probabilities = 0.5036. The heavily regularised logistic model was under-confident on dev
  out-of-fold predictions (slope 2.96, ECE 0.186); a Platt-style recalibration fitted on dev out-of-fold predictions only was folded into the coefficients.
* **Uncertainty**: participant-level bootstrap 95% CIs; AUC spread across the 5 outer repeats.
* **Holdout**: scored once for the reported figures.

### Disclosure — the holdout was looked at twice
A first pass of the pipeline, before recalibration, showed the holdout (specificity 0.759, ECE 0.178). The recalibration was then added **using dev data only** and the
identical seeded protocol re-run. The holdout therefore did influence the decision to add recalibration, even though no parameter was fitted to it. Treat the holdout
figures as slightly optimistic and not as a fully untouched test.

### Controls and confounding
* Label-permutation AUC over repeats: 0.43, 0.50, 0.51, 0.42, 0.51 → the pipeline does not leak the label.
* Recruitment-source-only AUC: 0.88 → source alone predicts the label almost as well as the questionnaire does, so the pooled AUC mixes real signal and collection-site effects.
* Source-stratified (non-`bdbp` sites, the only stratum with both classes in numbers): dev AUC 0.903 (n=121, only 21 controls);
  holdout AUC 0.909 (n=40, 7 controls). The `bdbp` site has only 2 ASD children and cannot be evaluated.

## 5. Limitations (all apply)
* case-control design: 53.6% ASD; prevalence in the intended population is far lower, so predicted probabilities are not population risk and PPV would be much lower
* recruitment source almost determines the label (bdbp# ids: 89 controls vs 2 ASD; FS/# ids: 80 ASD vs 12 controls): collection context is confounded with diagnosis
* Polish translation of the Q-CHAT, completed by caregivers in Poland; not validated for English-language or other populations
* ages 18-24 months only; sex imbalance (ASD 71% male, controls 52% male)
* ASD labels described as 'community-based diagnosis'; instruments used are not documented on the dataset page
* sibling_withASD is missing/0 for every control (structural), so it must never be a predictor
* Only 252 children; the holdout has 63, so every holdout figure has wide intervals.
* The cohort is ~54% ASD. Output is a **calibrated similarity to this cohort's ASD-group responses**, not the probability that a child has autism; positive predictive value in a general population would be far lower.
* Polish-language, Poland-recruited sample; no external validation; no English-language or NeuroSense-population data.
* The Q-CHAT-10 wording is © Autism Research Centre; clearance for use/adaptation in NeuroSense has not been obtained.

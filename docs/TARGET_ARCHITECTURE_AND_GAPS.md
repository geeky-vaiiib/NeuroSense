### Age and domain reconciliation

There is **no verified common age population across the four model branches**. The presentation targets early screening/children without a precise age window; app tracks are toddler 18–24 months, child 4–11 years and adult >=18 (age gaps unsupported). Polish data are toddlers in Poland; DASD age is unspecified beyond children; Cilia spans 2.7–12.9 years; adult questionnaire includes anomalies; expression/speech datasets are absent. An adult webcam operator smoke test cannot validate children or ASD discrimination.

Product/research dependency: select a primary age/language/task/device population with a clinical collaborator before facial/speech data acquisition. A reasonable engineering starting cohort is the existing child questionnaire age band, but **no such population choice is silently adopted here**. Separate age/domain models and evaluation remain necessary; do not pool by convenience. No model is extended across language, device, task or age by this phase.

### What can be built now, and what fusion needs

Can implement now: isolated model registry/contracts, separate measurement/expression/research-output namespaces, availability/null/provenance handling, consented capture/quality pipelines, offline participant-grouped evaluation and explanation interfaces. This phase implements the gaze harness, not all those future interfaces. With confirmed permission, DASD's paired gaze/AU numeric features can support a limited within-cohort association/fusion **experiment**, labelled as such, without pretending to train a face CNN. No speech/questionnaire alignment can be manufactured from them.

Blocked: training or validating four-way diagnostic fusion. Required manifest: dataset/site and pseudonymous participant/family IDs; session/task/time synchronization; questionnaire instrument/version/language/age; face/video and audio references; independent outcome label with assessor/instrument/date/provenance; modality availability/quality; consent/licence scope; shared split assignment. All sessions/windows/augmentations stay with the same participant/family. Learn transforms, base-model selection, calibration and fusion from development participants only; fusion training uses cross-fitted base predictions, never in-sample outputs. Check duplicate/overlapping recruitment across datasets using authorized linkage, not similarity-based identity guesses. Compare paired-cohort unimodal and fusion baselines with missing-modality ablations and an external independent evaluation. Unknown alignment is not evidence of independence.

## Gaze evidence reviewed and boundaries

Code inspected: `dasd.py`, frozen v3 config/metadata, preprocessing, quality/domain/service/inference modules, training and comparison scripts, existing leakage audit and reports. v3 consumes two session-centred angular channels on a 10 Hz grid, 6-second windows, mean of window scores. It measures a model association with cohort labels from angular distributions/sequences; it does not directly measure autism, calibrated screen position, eye contact, fixation, or attention to any stimulus. Gaze angles and head rotation cannot identify what was viewed without calibration/stimulus alignment. Quality/tracking confidence is not diagnostic confidence.

Existing reports (historical, not new training results): development BiLSTM mean AUC .8955; all-metadata LR .8975; time-shuffled .9342; label permutation .4865. Reported paired BiLSTM-minus-metadata LR interval [-.1532, .1337] includes zero. These do not establish an advantage over recording context or a temporal mechanism. Only saved arithmetic/source/configuration was independently checked in this phase. Official test participants influenced earlier design; frozen v3 trained on all82, so **no untouched DASD test remains**.

A concrete limitation in the old donor-swap audit was verified in code: it builds donor sequences from all development children before CV, then recipients can receive a held-out child's sequence. That control is transductive and cannot certify strict fold independence. Old cache files also lack a current input/source fingerprint. We leave the historical scripts/artifacts unchanged and do not upgrade their claim. The new harness uses within-participant/window shuffles only, produces a fresh private experiment and records data hashes/splits/code/environment.

## Prioritized implementation sequence

1. **Now — architecture/data reconciliation and gaze harness.** Deliver this inventory and GAZE_EXPERIMENT_PROTOCOL.md; test participant grouping, training-only transforms/gates, controls, null withholding, artifact integrity and blocked-data behavior. No runtime result changes.
2. **Next — execute permitted gaze development comparison.** Obtain an auditable DASD reuse reference (or a suitable permitted corpus), run the fixed command in a new private experiment directory, review exclusions/metadata/order/permutation controls and publish reviewed aggregates only. A new independent cohort is necessary for confirmatory evidence. Real usable-face capture remains a separate technical check.
3. **Facial expression first as its own task.** Choose target ages/task, confirm licensed identity-grouped expression/AU image data and annotation quality; build CNN plus simple baseline; subject-disjoint validation, subgroup/domain error report and actual-output attribution. Deploy only as an explicitly expression-labelled research capability when accepted. Do not relabel emotion as ASD. Separate later ASD association needs independently labelled matched children.
4. **Speech with a defined target.** Acquire licensed participant/speaker-labelled recordings in target language/task with speech/developmental and clinical provenance; audit diarisation, silence/clipping and language/hearing confounding; compare acoustic baseline and speech embeddings using grouped nested development evaluation. Resolve the current rate proxy's semantics before presenting any communication claim. No training on synthetic proxies.
5. **Fusion after paired-data readiness.** Collect/approve aligned cohort manifest; lock shared groups; compare unimodal baselines on the same cohort; cross-fit trainable fusion/calibration and missingness handling; validate externally. Keep instrument score, modality research outputs and any candidate fusion result as versioned separate records until their combination rule and evidence are approved.
6. **Explanation and application acceptance per model.** Bind explanation to actual output/input/model versions and units; preserve unavailable nulls and stored questionnaire scoring basis; add service/hardware/ownership/history/PDF tests. Release claims must match independently reproduced scope, not presentation aspirations.

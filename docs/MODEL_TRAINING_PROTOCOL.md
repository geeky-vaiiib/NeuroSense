# Local model training protocol v1

Baseline main fa4d192; this protocol is fixed before training. No DASD reuse, production access, paid compute or shipped-artifact overwrite. Research datasets are downloaded into ignored research-data/. Private manifests/caches/smoke outputs stay ignored; publish aggregate reports and versioned safe state-dict weights only.

Sources: Figshare 20113592 v1 CC BY4; V_Expression Mendeley 9gr9cn3bbn v1 CC BY4 (original file endpoint 403, user-authorized attributed emotion-course-data v1.0 redistribution); RAVDESS Zenodo1188976 v1 CC BY-NC-SA4, noncommercial research only. Archive checksums are verified. Facial release and individual image hashes verified; actual 127 people/889 images rather than description168/1176. No precomputed CLIP scores used. No identity inference or raw redistribution.

Split before augmentation/segmentation/windows: facial supplied held-out40 people remains test, development87 split train70/validation17 with seed20261104; speech actors split16/4/4, sex-balanced, same seed; gaze metadata participants stratified train60%/validation20%/test20%, same seed; one participant across every experiment stays grouped. Fit standardization/class weights only training. No oversampling or calibration. Missing/invalid data excluded with per-class counts. Source/metadata IDs are grouping keys, never input features. Check for duplicate content crossing groups.

Small two-epoch train/validation-only smoke first; not completed training or test evidence. Full candidates: facial compact 3-block grayscale64 CNN, max45epochs with training-only flip/translation/brightness augmentation; speech acoustic MFCC/statistics LR baseline plus compact log-Mel CNN max35epochs; gaze statistics LR baseline plus BiLSTM hidden24 max35epochs, metadata LR and within-window joint temporal shuffle control. AdamW lr.001 weight decay.01, batch32, CPU2 threads. Select epoch by validation macro-F1 (ties keep earlier), patience10. No test tuning. LR C=1 fixed. .5 threshold for binary results fixed; multiclass argmax. Scores are uncalibrated. Evaluate test once after selection; aggregate gaze windows by participant and speech chunks by recording.

Report counts/class balance, accuracy, balanced accuracy, macro-F1, per-class recall, confusion matrix; binary sensitivity/specificity/AUC; participant/speaker cluster-bootstrap95% intervals (1000 draws), not frame-level independence. Compare common-cohort baselines, metadata and order controls. Small held-out group counts and selected-corpus/device/language/task domains limit inference. No diagnostic validation or population autism probabilities claimed.

Facial/speech integration is restricted to adult technical research flows, with explicit unknown transfer/domain limitations; not toddler/child classification. A CNN is eligible for experimental display only if validation macro-F1>=.35 (face) / .30 (speech), and test balanced accuracy above chance; these are technical utility checks, not clinical cutoffs. No tuning after seeing test. Failed candidates stay offline. The eye-tracker candidate always stays offline from webcam inference because pixels/eye-tracker schema differ from OpenFace angles; preserve frozen webcam checkpoint and existing gates. A trained emotion model never becomes an ASD model. No diagnostic fusion without genuine participant-paired data.

ASD speech candidates are investigated separately for labels, access and speaker IDs; inaccessible or unverified data blocks that task, not emotion training. Reproduction commands, model hashes, environments and actual results will be recorded after execution. Test inference never fabricates zero output on failure.
